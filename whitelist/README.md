# LITA Whitelist Portraits Directory

Drop your authenticated `.jpg` (or `.png`) portrait profiles in this directory.
LITA will pre-compute and cache facial embeddings for these files at startup.

Naming convention:
Use the person's name as the filename (e.g., `john_doe.jpg` or `jane_doe.jpg`).
LITA will display this name as the 'KNOWN' label on the HUD.
